# Mr. Whiskerfact: formats

Each reel uses one format. They share the brand rules (colours, hook from frame 0, subtitles, outro) but have different structures, so the channel never looks like one template repeated. The nightly run chooses the format with the `format` test in `growth/experiments.json`.

| Format | Hook on screen (frame 0) | Structure |
|---|---|---|
| **explainer** | "Why do we get goosebumps?" | hook → context → 2–3 numbered steps → surprising fact → closing |
| **myth** | "MYTH OR FACT? Goldfish have a 3-second memory." | the belief, stated big → a stamp appears (MYTH / FACT / HALF TRUE) after a 1 s beat → where the belief comes from → what the evidence shows (2 steps) → the real answer → closing |
| **versus** | "Cheetah vs pronghorn: who wins a marathon?" | split screen: two sides with matching drawings → 3 rounds (each a stat or property, a bar or score that grows, one winner per round) → the twist → final score → closing |
| **what_if** | "What if the Moon disappeared tonight?" | the premise → first minute or hour → first day → long term → what it teaches us about the real world → closing. Only use effects that published scientists describe, and say "scientists expect" |
| **quiz** | "Pop quiz: which is older, sharks or trees?" | question with 3 options (A, B, C) on screen → "Comment your answer before I tell you" plus a 2-second ticking clock → reveal with stamp → why → closing |

## Rules
- The `myth` format needs a myth that is really widely believed (demand check), plus a source that addresses the myth directly.
- `versus` must compare like with like, using the same units.
- `quiz` options must all be plausible, and the wrong options must be verifiably wrong.
- `what_if` must never be scary-for-effect or catastrophising. Real disasters and wars belong in neutral `explainer` or `myth` reels, never in hypotheticals.
- Every format keeps the length and retention rules in FACTORY.md step 4, the precision check and the hard limits in PERSONALITY.md.
- Structures are a guide, not a cage: reorder or merge steps when it keeps people watching better, as long as the hook is on screen from frame 0 and the payoff comes near the end.

## Closing bank (one line before "Class dismissed. Stay curious.")
Pick one type per reel (FACTORY.md step 4) and write the line fresh for the topic; never reuse an earlier reel's wording. "So next time…, now you know" is retired as the default (it was used in every reel up to 1/11/2026); it may come back only rarely.
| Type | Example |
|---|---|
| **bonus** | one extra, verified mini-fact: "Bonus: dolphins can do this for up to 15 days." |
| **callback** | turn the hook around: "So, open eye, sleeping brain. Half asleep, fully awesome." |
| **ask** | a question for the comments, tied to the topic: "Would you rather sleep like a dolphin? Tell me below." |
| **cat_take** | Mr. Whiskerfact's own light opinion (PERSONALITY.md): "Honestly? Best sleeping trick in the ocean." |
| **real_life** | where the viewer will meet it: "You'll never look at a bat the same way on Halloween." |
| **mind_blown** | a scale or comparison that lands the point: "That's hotter than a pizza oven. Every single day." |
| **now_you_know** | the old line, at most once in 10 reels |
Light types (cat_take, callback with a joke) never on sensitive topics: use bonus or real_life there.
